# reflexion-agent

An Actor-Critic extension of [Reflexion](https://arxiv.org/abs/2303.11366) for multi-hop QA. The
Actor answers a HotPotQA question from retrieved context; when the answer is judged wrong, a
separate Critic writes a short reflection into a persistent FAISS memory, and the Actor retries with
the most relevant past reflections. Memory carries across questions, so later questions benefit from
earlier mistakes. Three Actor reasoning strategies (Chain-of-Thought, ReAct, multi-hop decomposition)
plug into the same Critic.

Every run writes the model that answered, the config, per-question predictions, every attempt and
reflection, and an error count. A run with any failed LLM call is marked invalid. See
[docs/PROVENANCE.md](docs/PROVENANCE.md) for why.

Reading:
- Reflection memory with a paper-faithful binary critic lifts RAG-only from 63% to 71% relaxed EM (+8 points, 95% interval about ±4 at n=500). The gain is real.
- The notebook's oracle critic, which sees the gold answer, reaches 83%. The extra +12 points is label leakage, not learning.
- Actor strategy does not matter: CoT, ReAct and multi-hop land at 71 to 72%. The notebook's "multi-hop best at 80%" was n=50 noise plus the leak.
- Full context (no retrieval) beats every RAG condition by 9 points, so k=3 chunk retrieval is the bottleneck, not reasoning. Reranking or larger k is the next experiment.

## Setup

```bash
uv venv && source .venv/bin/activate
uv pip install -e ".[dev]"
cp .env.example .env   # point LLM_BASE_URL / LLM_MODEL at any OpenAI-compatible server
pytest
```

Works with Ollama (`http://localhost:11434/v1`), vLLM, LM Studio, or a hosted API. Embeddings for
RAG and memory go through the same server's `/v1/embeddings` by default (Ollama: `ollama pull
nomic-embed-text`), so no torch install is needed. To embed locally with sentence-transformers
instead (the notebook used `BAAI/bge-base-en-v1.5`), `uv pip install -e ".[st]"` and set
`EMBED_BACKEND=st EMBED_MODEL=BAAI/bge-base-en-v1.5`. The first run downloads HotPotQA
(distractor, validation).

## Run

```bash
# paper-faithful critic (binary feedback), all three conditions, CoT actor
reflexion run --model qwen2.5:7b --n 50 --seed 42 --trials 3

# reproduce the notebook's setup (critic sees the gold answer)
reflexion run --critic-feedback oracle

# actor strategy sweep
for s in cot react multihop; do reflexion run --strategy $s --conditions actor_critic; done

# speed: conditions already run concurrently; --workers fans out the stateless baselines (vLLM batches them).
# actor_critic stays sequential because reflection memory accumulates across questions in order.
reflexion run --n 500 --workers 8 --no-think

# table of every run
reflexion report
```

Output lands in `results/<model>/<timestamp>_<strategy>_<critic>/` as `config.json`,
`per_question.csv`, `attempts.jsonl`, `summary.json`. Accuracy is reported under two scorers:
relaxed (notebook rule, substring match either way) and strict (official HotPotQA normalisation).

## Layout

```
src/reflexion_agent/
  config.py     RunConfig: every knob that can change a number
  llm.py        OpenAI-compatible client with retries; LLMError, never a fake answer
  data.py       HotPotQA load + seed-deterministic sample
  retrieval.py  recursive chunker, OpenAI-compatible or local embeddings, FAISS cosine index, ReflectionMemory
  prompts.py    actor strategies (cot / react / multihop), critic (binary / oracle)
  scoring.py    final-answer extraction, relaxed and strict EM
  agent.py      ActorCritic.solve: attempt, reflect, retry, keep best
  runner.py     conditions, result files, error accounting
  report.py     summary.json -> markdown table
  cli.py        reflexion run / reflexion report
tests/          27 tests, no network, fake LLM and hash embedder
```
